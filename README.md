## 🚀 Projet principal — XALDIA

### [XALDIA — MMORPG 2D Web](https://xaldia.com)

XALDIA est un **MMORPG 2D multijoueur pour navigateur** que je développe comme projet personnel.

Le projet a commencé comme un petit jeu web et a beaucoup évolué depuis. C'est aujourd'hui un projet client-serveur complet qui me permet d'apprendre et d'expérimenter avec plusieurs aspects du développement logiciel.

**Quelques technologies et concepts utilisés :**

- JavaScript / Node.js
- PixiJS 8 / WebGL
- WebSocket
- PostgreSQL
- serveur authoritative
- authentification et gestion des sessions
- client-side prediction et interpolation
- tests automatisés
- Linux / Ubuntu Server
- systemd
- Git / GitHub
- déploiement sur VPS

Le code source principal est privé, mais le jeu est accessible en ligne.

👉 **[Voir XALDIA](https://xaldia.com)**

## 💻 Autres projets

### 🎓 [Académie Backend](https://github.com/Charleslegault1992/academie-backend)

API backend développée pour une plateforme de cours en ligne de type mini-Moodle.

Le projet comprend entre autres l'inscription et la connexion des utilisateurs, des routes protégées avec JWT, la gestion de rôles **Étudiant / Formateur / Admin**, ainsi que la gestion des cours, leçons, inscriptions, progression et quiz.

**Stack :** `TypeScript` · `Node.js` · `Express` · `Prisma` · `Neon PostgreSQL` · `JWT` · `bcrypt`

---

### 🌳 [Arbreal](https://github.com/Charleslegault1992/arbreal)

Application qui permet de visualiser sur une carte des données d'arbres publics de Montréal.

Les données CSV sont traitées dans l'application, converties en données géographiques et affichées sur une carte interactive.

**Stack :** `Vue 3` · `Tauri 2` · `Vite` · `MapLibre GL` · `Papa Parse`
